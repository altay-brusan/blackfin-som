BECOM Systems Tinyboard Support Package V1.3.0 
-------------------------------------------------------------

Copyright (c) BECOM Systems GmbH 2019

This software package contains the flash driver source code, 
the driver for the VDSP++ Flash Programming Tool 
and the binaries and executables of the BLACKSheep bootloader
for the Blackfin based core modules.

//////////////////////////////////////////////////////////////////////////
PACKAGE CONTENT:
- bsboot
    Binary and executable of the BLACKSHeep bootloader

- flash-driver-src
    Source code of the flash driver

- VDSP-flash-tool-driver
    Driver for the VDSP++ Flash Programming Tool

Please select the article number of your core module.
//////////////////////////////////////////////////////////////////////////
