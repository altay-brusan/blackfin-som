This repository contains example projects that supports developper during their first steps.

getting_started_examples:
    The getting started examples are a collection of useful projects to test part of the core module.
    
    GPIO:
        A GPIO toggles --> LED blinks
        
        Location:
            prj_VDSP5.0\BLT\getting_started_examples\GPIO\cm-bf527\blink_cm-bf527.dpj
            prj_VDSP5.0\BLT\getting_started_examples\GPIO\cm-bf533\blink_cm-bf533.dpj
            prj_VDSP5.0\BLT\getting_started_examples\GPIO\cm-bf537e\blink_cm-bf537e.dpj
            prj_VDSP5.0\BLT\getting_started_examples\GPIO\cm-bf548\blink_cm-bf548.dpj
            prj_VDSP5.0\BLT\getting_started_examples\GPIO\cm-bf561\blink_cm-bf561.dpj
            prj_VDSP5.0\BLT\getting_started_examples\GPIO\tcm-bf518\blink_tcm-bf518.dpj
    
    Sockets:
        A socket is opened and every incomming data is looped back.
        
        Location:
            prj_VDSP5.0\BLT\getting_started_examples\Sockets\cm-bf527\SocketExample_CM_BF527.dpj
